# V. 네트워크 장비 / 4. 로그 관리

## 항목 코드

NW-15 ~ NW-18

## 분류

V. 네트워크 장비 > 4. 로그 관리

## 항목명

4. 로그 관리

## 개요

네트워크 로그 수집, 보관, 이벤트 검출 기준

## 점검 내용

- 해당 항목은 운영 환경에서 보안 정책 및 기본 설정을 확인하는 항목입니다.
- 시스템별 구성과 정책을 함께 검토하여 운영 상태를 평가합니다.
- 세부 점검 값은 실제 배포 환경의 설정, 패치 상태, 오픈 포트, 사용자 권한 정책을 함께 고려해야 합니다.

## 점검 목적

- 설정이 의도대로 반영되어 있는지 확인합니다.
- 권한 남용, 불필요한 접근, 관리자 우회 가능성 등 보안 위험을 사전에 차단합니다.
- 취약한 설정이 실제 공격 경로로 연결되는지를 점검합니다.

## 보안 위협

- 불필요한 권한 부여 또는 기본 설정 오남용
- 공격자가 계정 또는 관리 기능을 악용할 수 있는 경로 존재
- 관리 권한이 과도하게 허용되어 데이터 또는 시스템 무결성이 훼손될 수 있음

## 참고

- 원문 PDF의 해당 항목을 함께 확인해야 합니다.
- 운영 정책, 보안 표준, 패치 상태, 장비/OS 버전에 따라 판단 기준이 다를 수 있습니다.

## 점검 대상 및 판단 기준

### 대상

- Solaris, Linux, AIX, HP-UX 등 관련 운영 환경
- 해당 항목과 연관된 보안 정책 및 운영 절차

### 판단 기준

- 양호: 보안 정책에 따라 필요한 제한이 정상적으로 구현된 경우
- 취약: 보안 설정이 부재하거나 일반 사용자가 과도하게 접근/이용 가능한 경우

## 조치 방법

- 최소 권한 원칙에 따라 계정 및 접근 권한을 제한합니다.
- 불필요한 기능, 권한, 기본 계정, 접근 경로를 제거하거나 비활성화합니다.
- 운영 절차 및 보안 정책을 반영해 정기적으로 검토 및 재점검합니다.

## 점검 및 조치 사례

- 실제 설정 상태를 확인하고 로그/권한/운영 절차와 함께 비교 검토합니다.
- 보안상 위험이 확인되면 설정값을 조정하고, 재점검으로 정상 적용 여부를 확인합니다.
