## 점검 항목

- [1. 계정 관리](unix-server/unix-account-management.md) — root 원격 접속 제한, 비밀번호 정책, 잠금 임계값, 비밀번호 파일 보호, 계정/UID/GID 점검 등
- [2. 파일 및 디렉터리 관리](unix-server/unix-file-directory-management.md) — root 홈·PATH 설정, 파일 소유자 권한, 파일 시스템 권한, 숨김 파일 관리, 익명 접근 제한 등
- [3. 서비스 관리](unix-server/unix-service-management.md) — 서비스 실행 권한, 불필요 서비스 비활성화, 익명 서비스 제한, 포트 및 프로세스 점검
- [4. 패치 관리](unix-server/unix-patch-management.md) — OS/패키지/보안 업데이트 적용 여부와 패치 반영 기준 점검
- [5. 로그 관리](unix-server/unix-log-management.md) — 로그 기록, 보관 기간, 접근 및 변경 추적 관점의 로그 점검
- [U-01 root 계정 원격 접속 제한](unix-server/u-01.md) — 원격 환경에서 root 계정 직접 접속을 제한하고, 관리자 권한 사용을 필요한 계정으로만 제한한다.
- [U-02 비밀번호 관리정책 설정](unix-server/u-02.md) — 비밀번호 길이, 변경주기, 복잡도, 기억 정책 등을 적절히 구성하여 계정 도용을 방지한다.
- [U-03 계정 잠금 임계값 설정](unix-server/u-03.md) — 로그인 실패 횟수, 잠금 기간, 잠금 방식 등을 설정해 무차별 대입 공격을 차단한다.
- [U-04 비밀번호 파일 보호](unix-server/u-04.md) — 패스워드 파일 접근 권한과 보안 설정을 점검해 계정 정보 노출을 방지한다.
- [U-05 root 이외의 UID가 '0' 금지](unix-server/u-05.md) — 관리자 권한을 가진 사용자가 다른 계정에서도 UID 0을 가지지 않도록 제한한다.
- [U-06 사용자 계정 su 기능 제한](unix-server/u-06.md) — su 명령을 허용할 사용자를 제한하여 비관리자 계정의 관리자 권한 전환을 방지한다.
- [U-07 불필요한 계정 제거](unix-server/u-07.md) — 필요 없는 기본 계정, 테스트 계정, 임시 계정 등을 제거하여 무단 접근 경로를 최소화한다.
- [U-08 관리자 그룹에 최소한의 계정 포함](unix-server/u-08.md) — 관리자 권한 그룹에는 실제 필요한 계정만 포함되도록 제한한다.
- [U-09 계정이 존재하지 않는 GID 금지](unix-server/u-09.md) — 존재하지 않는 그룹 ID를 참조하는 계정 설정을 방지하여 권한 매핑 오류를 막는다.
- [U-10 동일한 UID 금지](unix-server/u-10.md) — 같은 UID를 가진 계정이 존재하지 않도록 점검하여 권한 충돌을 방지한다.
- [U-11 사용자 Shell 점검](unix-server/u-11.md) — 불필요한 셸이나 비대화형 셸이 계정에 할당되지 않도록 점검한다.
- [U-12 세션 종료 시간 설정](unix-server/u-12.md) — 장시간 미사용 세션이 유지되지 않도록 자동 종료 정책을 설정한다.
- [U-13 안전한 비밀번호 암호화 알고리즘 사용](unix-server/u-13.md) — 취약한 해시 알고리즘 대신 안전한 암호화 방식으로 비밀번호를 저장하도록 점검한다.
