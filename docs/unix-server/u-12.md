## 점검 대상 및 판단 기준

| 구분 | 내용 |
|---|---|
| 대상 | SOLARIS, LINUX, AIX, HP-UX 등 |
| 양호 | Session Timeout이 600초(10분) 이하로 설정된 경우 |
| 취약 | Session Timeout이 600초(10분) 이하로 설정되지 않은 경우 |
| 조치 방법 | 600초(10분) 동안 입력이 없는 경우 접속된 Session을 끊도록 설정 |
| 조치 시 영향 | 모니터링 용도일 경우 세션 타임 설정 시 모니터링 업무가 불가할 수 있으므로 예외 처리 필요 |

## AI 추천 점검 및 조치 방법

### 점검 포인트

- /etc/profile, /etc/bashrc, /etc/csh.cshrc 등 사용자 쉘 환경 파일에서 `TMOUT` 또는 `autologout` 값이 설정되어 있는지 확인한다.
- 세션 타임아웃 값이 600초(10분) 이하로 적절히 설정되었는지 점검한다.
- 비인가 접근 또는 장시간 미사용 세션 유지 여부를 로그와 함께 확인한다.

### 권장 조치

```bash
# [sh, ksh, bash]
Step 1) /etc/profile 파일 내 TMOUT 값 설정
TMOUT=600
export TMOUT

# [csh]
Step 1) /etc/csh.cshrc 또는 /etc/csh.login 파일 내 autologout 값 설정
set autologout=10
```

### 확인 근거

- 설정 파일과 운영 절차를 비교해 적용 상태를 확인한다.
- 유휴 시간 동안 세션을 유지하는 사용자를 식별하고 비정상 세션 여부를 확인한다.
- 보안 정책에 따라 조치 후 재점검 결과를 기록한다.

## 점검 및 조치 사례

### 점검 예시

```bash
# [sh, ksh, bash]
grep -E 'TMOUT|readonly TMOUT' /etc/profile /etc/bashrc /etc/csh.cshrc

# [csh]
grep -E 'autologout' /etc/csh.cshrc /etc/csh.login
```

### 조치 예시

- 사용자 쉘 환경 설정 파일에서 세션 타임아웃 값을 600초 이하로 조정한다.
- 모니터링 도구 또는 자동화 작업 등 예외적인 운영 상황이 있는 경우, 승인된 예외만 적용한다.
- 조치 이후 설정 파일 값과 실제 로그를 재검증한다.
