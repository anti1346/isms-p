# UNIX > 1. 계정 관리 / U-02

## 항목별 점검서

| 구분 | 내용 |
|---|---|
| 항목 코드 | U-02 |
| 항목명 | 비밀번호 관리정책 설정 |
| 분류 | UNIX > 1. 계정 관리 |
| 점검 내용 | 비밀번호 길이, 변경주기, 복잡도, 기억 정책 등을 적절히 구성하여 계정 도용을 방지한다. |
| 점검 항목 | - 최소 길이 및 복잡도 정책 점검<br>- 최대/최소 비밀번호 사용 기간 점검<br>- 암호 정책 준수 여부 확인 |
| 점검 목적 | 권한 과다 부여, 계정 도용, 비인가 접근 경로를 사전에 차단하여 운영 보안을 유지한다. |
| 보안 위협 | 불필요한 권한 부여, 기본 설정 오남용, 관리자 계정 침해, 무차별 대입 공격 등 보안 사고로 이어질 수 있다. |

## 점검 대상 및 판단 기준

| 구분 | 내용 |
|---|---|
| 대상 | Solaris, Linux, AIX, HP-UX 등 UNIX 계열 운영체제 및 계정/권한 관리 설정 |
| 양호 | 양호: 비밀번호 관리정책 설정 관련 설정이 정책에 따라 적절하게 적용되어 있는 경우 |
| 취약 | 취약: 비밀번호 관리정책 설정 관련 설정이 누락되었거나 기본값으로 남아 있어 보안 위험이 존재하는 경우 |
| 조치 방법 | 보안 정책에 따라 설정을 조정하고, 불필요한 권한과 기본값을 제거한 뒤 재점검을 수행한다. |

## 점검 및 조치 사례

### 점검 예시

```bash
grep -E 'PASS_MAX_DAYS|PASS_MIN_DAYS|PASS_WARN_AGE|PASS_MIN_LEN' /etc/login.defs
```

### 조치 예시

- 보안 정책을 반영한 계정/권한 설정을 정리한다.
- 불필요한 관리자 권한 또는 기본 설정을 정리한다.
- 변경 사항을 적용한 뒤 다시 점검 로그를 확인한다.
