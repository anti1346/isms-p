# UNIX > 1. 계정 관리 / U-05

## 항목별 점검서

| 구분 | 내용 |
|---|---|
| 항목 코드 | U-05 |
| 항목명 | root 이외의 UID가 '0' 금지 |
| 분류 | UNIX > 1. 계정 관리 |
| 점검 내용 | 관리자 권한을 가진 사용자가 다른 계정에서도 UID 0을 가지지 않도록 제한한다. |
| 점검 항목 | - UID 0 사용자 계정 점검<br>- 관리자 계정의 중복 여부 확인<br>- 권한 분리 원칙 준수 |
| 점검 목적 | 권한 과다 부여, 계정 도용, 비인가 접근 경로를 사전에 차단하여 운영 보안을 유지한다. |
| 보안 위협 | 불필요한 권한 부여, 기본 설정 오남용, 관리자 계정 침해, 무차별 대입 공격 등 보안 사고로 이어질 수 있다. |

## 점검 대상 및 판단 기준

| 구분 | 내용 |
|---|---|
| 대상 | Solaris, Linux, AIX, HP-UX 등 UNIX 계열 운영체제 및 계정/권한 관리 설정 |
| 양호 | 양호: root 이외의 UID가 '0' 금지 관련 설정이 정책에 따라 적절하게 적용되어 있는 경우 |
| 취약 | 취약: root 이외의 UID가 '0' 금지 관련 설정이 누락되었거나 기본값으로 남아 있어 보안 위험이 존재하는 경우 |
| 조치 방법 | 보안 정책에 따라 설정을 조정하고, 불필요한 권한과 기본값을 제거한 뒤 재점검을 수행한다. |

## 점검 및 조치 사례

### 점검 예시

```bash
awk -F: '$3 == 0 {print $1, $3}' /etc/passwd; getent group
```

### 조치 예시

- 보안 정책을 반영한 계정/권한 설정을 정리한다.
- 불필요한 관리자 권한 또는 기본 설정을 정리한다.
- 변경 사항을 적용한 뒤 다시 점검 로그를 확인한다.
