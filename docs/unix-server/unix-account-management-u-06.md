# UNIX > 1. 계정 관리 / U-06

## 항목 코드

U-06

## 항목명

사용자 계정 su 기능 제한

## 개요

su 명령어 사용을 허용하는 사용자를 지정한 그룹이 설정되었는지 점검합니다.

## 점검 내용

- su 명령어 사용 가능 사용자를 특정 그룹으로 제한하였는지 확인
- 일반 사용자의 su 명령 사용을 원천적으로 차단하는지 점검
- root 계정 전환을 허용할 사용자 범위를 명확히 통제하는지 확인

## 점검 목적

- 무분별한 사용자 전환 방지
- 타 사용자 소유 파일 변경 및 관리자 권한 획득 위험 감소
- 계정 권한 남용 및 시스템 오남용 방지

## 보안 위협

- 일반 사용자가 root 또는 타 사용자 권한으로 전환 가능
- 관리자 권한을 쉽게 획득할 수 있어 보안 사고로 연결될 수 있음
- 파일 무결성 훼손, 시스템 설정 변경, 악성 행위 실행 가능

## 점검 대상 및 판단 기준

### 대상

- Solaris
- Linux
- AIX
- HP-UX 등 UNIX 계열 운영체제

### 판단 기준

- 양호: su 명령어를 특정 그룹에 속한 사용자만 사용할 수 있도록 제한된 경우
- 취약: su 명령어를 모든 사용자가 사용할 수 있도록 설정된 경우

> 일반 사용자 계정 없이 root 계정만 사용하는 경우에는 su 명령어 사용 제한이 불필요할 수 있습니다.

## 조치 방법

- PAM 모듈 설정을 통해 su 사용 제한 적용
- su 명령어 허용 그룹을 별도로 생성하고, 필요한 관리자만 해당 그룹에 포함
- 일반 사용자 계정은 su 명령 수행 권한에서 제거
- 설정 반영 후 세션 종료와 재로그인을 요구하여 적용 상태를 확인

## 점검 및 조치 사례

- 관리자 그룹에만 su 사용 권한을 부여한 후, 일반 계정으로 su 실행 시 실패 여부 확인
- 특정 그룹에 권한이 없는 계정이 su 명령을 실행할 수 없는지 확인
- 설정 변경 후 로그를 통해 정당한 사용자만 su 사용되었는지 검토
