## AI 추천 점검 및 조치 방법

### 점검 포인트

- 계정이 존재하지 않는 GID 금지 관련 설정값이 실제 운영 환경에 적용되어 있는지 확인한다.
- 그룹 ID 유효성 점검 항목을 우선 점검하고, 정책상 허용 범위를 초과하는 설정이 있는지 확인한다.
- 관련 로그 및 사용자 권한 기록을 함께 조회하여 실제 보안 상태를 검증한다.

### 권장 조치

- 보안 정책에 따라 계정이 존재하지 않는 GID 금지 관련 설정을 최소 권한 원칙에 맞게 정리한다.
- 불필요한 권한, 기본값, 예외 설정을 제거하거나 제한한다.
- 변경 후 재점검을 수행하고 보안 로그와 정책 준수 여부를 확인한다.

### 확인 근거

- 설정 파일과 운영 절차를 비교하여 실제 적용 상태를 확인한다.
- 사용자 권한, 접근 로그, 계정 목록을 함께 확인해 불필요한 허용 상태를 검출한다.
- 보안 위협이 확인될 경우 구성 변경과 재점검 결과를 기록한다.

## 점검 및 조치 사례

### 점검 예시

```bash
awk -F: '$3 == 0 {print $1, $3}' /etc/passwd; getent group
```

### 조치 예시

- 보안 정책을 반영한 계정/권한 설정을 정리한다.
- 불필요한 관리자 권한 또는 기본 설정을 정리한다.
- 변경 사항을 적용한 뒤 다시 점검 로그를 확인한다.
