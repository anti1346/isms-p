# UNIX > 1. 계정 관리 / U-07

## 항목 코드

U-07

## 항목명

불필요한 계정 제거

## 개요

필요 없는 기본 계정, 테스트 계정, 임시 계정 등을 제거하여 무단 접근 경로를 최소화한다.

## 점검 내용

- 사용하지 않는 계정 식별
- 기본 계정 보안 설정 점검
- 계정 사용 기록 검토

## 점검 목적

- 실제 정책 반영 여부를 검증한다.
- 권한 침해 또는 관리자 권한 과다 할당 가능성을 사전에 차단한다.
- 운영 환경의 위험 요소를 확인하고 보안 수준을 유지한다.

## 보안 위협

- 계정 도용 또는 무단 접근 가능성
- 관리자 권한 오남용 및 시스템 무결성 훼손
- 보안 정책이 무력화되어 침해 사고로 이어질 수 있음

## 점검 대상 및 판단 기준

### 대상

- Solaris, Linux, AIX, HP-UX 등 UNIX 계열 운영체제
- 계정, 패스워드, 권한 정책, 세션 관리 설정

### 판단 기준

- 양호: 정책에 따라 필요한 제한이 정상적으로 반영된 경우
- 취약: 기본값 노출, 과도한 권한 부여, 설정 누락이 발견된 경우

## 조치 방법

- 보안 정책을 준수하도록 설정을 수정한다.
- 불필요한 권한 또는 기본 설정을 제거한다.
- 적용 후 재점검을 통해 정상 동작 여부를 확인한다.

## 점검 및 조치 사례

- 운영 환경에서 현재 설정값을 확인하고 보안 정책 대비 비교한다.
- 취약한 설정이 발견되면 정책을 보강하고, 적용 여부를 검증한다.
