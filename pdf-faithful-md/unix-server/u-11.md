# U-11 사용자 Shell 점검

| 구분 | 내용 |
| :--- | :--- |
| **개요** | |
| 점검 내용 | 로그인이 불필요한 계정의 shell 값과 사용자 shell 설정을 점검한다. |
| 점검 목적 | 시스템 계정이나 비대화형 계정이 실제 로그인을 허용하지 않도록 하기 위함 |
| 보안 위험 | 불필요한 shell을 가진 계정은 로그온 시 공격 경로가 될 수 있다. |
| 참고 | ※ 해당 항목은 운영 환경 및 정책에 따라 세부 설정이 달라질 수 있다. |
| **점검 대상 및 판단 기준** | |
| 대상 | SOLARIS, LINUX, AIX, HP-UX 등 |
| 판단 기준 | **양호**: 시스템 계정 및 로그인이 불필요한 계정은 /sbin/nologin 또는 /bin/false로 제한된 경우<br>**취약**: 무분별하게 빈 shell 또는 로그인 가능한 shell이 부여된 경우 |
| 조치 방법 | 로그인이 필요하지 않은 계정의 shell을 /bin/false 또는 /sbin/nologin으로 변경한다. |
| 조치 시 영향 | 일반적인 경우 영향 없음 |

## 점검 및 조치 사례

```bash
cat /etc/passwd | grep -E 'daemon|bin|sys|adm|nobody'
# 필요 시
usermod -s /bin/false <계정명>
```

## AI 추천 점검 및 조치 방법

### 점검 포인트
- 해당 항목의 설정값이 실제 운영 환경에서 적용되는지 확인한다.
- 정책 기준과 현재 설정값을 비교한다.
- 로그와 사용자 권한 상태를 함께 확인한다.

### 권장 조치
```bash
cat /etc/passwd | grep -E 'daemon|bin|sys|adm|nobody'
```

- 보안 정책을 반영해 설정을 조정한다.
- 불필요한 예외 설정을 제거한다.
- 변경 후 재점검을 수행한다.
