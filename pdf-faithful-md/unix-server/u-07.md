# U-07 불필요한 계정 제거

| 구분 | 내용 |
| :--- | :--- |
| **개요** | |
| 점검 내용 | 사용하지 않는 기본 계정, 테스트 계정, 임시 계정의 존재 여부를 점검한다. |
| 점검 목적 | 불필요한 계정으로 인한 권한 오남용과 공격 벡터를 줄이기 위함 |
| 보안 위험 | 사용하지 않는 계정이 남아 있으면 비인가 접근 및 의도치 않은 권한 획득이 가능하다. |
| 참고 | ※ 해당 항목은 운영 환경 및 정책에 따라 세부 설정이 달라질 수 있다. |
| **점검 대상 및 판단 기준** | |
| 대상 | SOLARIS, LINUX, AIX, HP-UX 등 |
| 판단 기준 | **양호**: 필요한 계정만 유지되고 불필요한 계정이 정리된 경우<br>**취약**: 기본 계정이나 임시 계정이 남아 있거나 사용하지 않는 계정이 관리되지 않는 경우 |
| 조치 방법 | 불필요한 계정을 삭제하거나 shell을 /bin/false로 바꾸어 비활성화한다. |
| 조치 시 영향 | 일반적인 경우 영향 없음 |

## 점검 및 조치 사례

```bash
cut -d: -f1 /etc/passwd
getent passwd | awk -F: '{print $1,$3}'
```

## AI 추천 점검 및 조치 방법

### 점검 포인트
- 해당 항목의 설정값이 실제 운영 환경에서 적용되는지 확인한다.
- 정책 기준과 현재 설정값을 비교한다.
- 로그와 사용자 권한 상태를 함께 확인한다.

### 권장 조치
```bash
cut -d: -f1 /etc/passwd
```

- 보안 정책을 반영해 설정을 조정한다.
- 불필요한 예외 설정을 제거한다.
- 변경 후 재점검을 수행한다.
