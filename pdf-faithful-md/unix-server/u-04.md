# U-04 비밀번호 파일 보호

| 구분 | 내용 |
| :--- | :--- |
| **개요** | |
| 점검 내용 | /etc/passwd, /etc/shadow 파일의 소유자, 권한 및 접근 가능 여부를 점검한다. |
| 점검 목적 | 계정 정보의 노출을 방지하고 비인가 접근 경로를 차단하기 위함 |
| 보안 위험 | 패스워드 파일 접근 권한이 과도하게 허용되면 계정 정보 탈취가 가능하다. |
| 참고 | ※ 해당 항목은 운영 환경 및 정책에 따라 세부 설정이 달라질 수 있다. |
| **점검 대상 및 판단 기준** | |
| 대상 | SOLARIS, LINUX, AIX, HP-UX 등 |
| 판단 기준 | **양호**: /etc/shadow 등 민감 파일이 관리자만 접근 가능하게 보호되는 경우<br>**취약**: 일반 사용자에게 읽기 권한이 허용되거나 민감 파일이 불필요하게 오픈된 경우 |
| 조치 방법 | 민감한 파일의 소유자와 권한을 제한하고, 불필요한 접근 권한을 제거한다. |
| 조치 시 영향 | 일반적인 경우 영향 없음 |

## 점검 및 조치 사례

```bash
ls -l /etc/passwd /etc/shadow
stat -c '%A %U %G %n' /etc/passwd /etc/shadow
```

## AI 추천 점검 및 조치 방법

### 점검 포인트
- 해당 항목의 설정값이 실제 운영 환경에서 적용되는지 확인한다.
- 정책 기준과 현재 설정값을 비교한다.
- 로그와 사용자 권한 상태를 함께 확인한다.

### 권장 조치
```bash
ls -l /etc/passwd /etc/shadow
```

- 보안 정책을 반영해 설정을 조정한다.
- 불필요한 예외 설정을 제거한다.
- 변경 후 재점검을 수행한다.
