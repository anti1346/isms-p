# U-09 계정이 존재하지 않는 GID 금지

| 구분 | 내용 |
| :--- | :--- |
| **개요** | |
| 점검 내용 | 계정의 GID가 실제로 존재하는 그룹을 가리키는지 점검한다. |
| 점검 목적 | 잘못된 그룹 참조로 인한 권한 오류를 방지하기 위함 |
| 보안 위험 | 존재하지 않는 GID를 가진 계정은 권한 문제가 발생할 수 있다. |
| 참고 | ※ 해당 항목은 운영 환경 및 정책에 따라 세부 설정이 달라질 수 있다. |
| **점검 대상 및 판단 기준** | |
| 대상 | SOLARIS, LINUX, AIX, HP-UX 등 |
| 판단 기준 | **양호**: 모든 계정의 GID가 실제 존재하는 그룹에 매핑된 경우<br>**취약**: 존재하지 않는 group id를 가리키는 계정이 존재하는 경우 |
| 조치 방법 | 계정의 GID를 정합성 있게 수정하고, 사용하지 않는 그룹을 정리한다. |
| 조치 시 영향 | 일반적인 경우 영향 없음 |

## 점검 및 조치 사례

```bash
getent group; awk -F: '{print $1,$3}' /etc/passwd
```
