# U-06 사용자 계정 su 기능 제한

| 구분 | 내용 |
| :--- | :--- |
| **개요** | |
| 점검 내용 | su 사용 허용 그룹 및 sudo 정책을 점검한다. |
| 점검 목적 | 관리자 권한 전환 범위를 최소화하여 권한 남용을 방지하기 위함 |
| 보안 위험 | 일반 사용자가 su를 통해 루트 권한을 탈취하면 관리자 권한을 무단으로 사용할 수 있다. |
| 참고 | ※ 해당 항목은 운영 환경 및 정책에 따라 세부 설정이 달라질 수 있다. |
| **점검 대상 및 판단 기준** | |
| 대상 | SOLARIS, LINUX, AIX, HP-UX 등 |
| 판단 기준 | **양호**: su 또는 sudo를 허용하는 사용자가 필요한 인원만 제한되어 있는 경우<br>**취약**: 일반 사용자가 무분별하게 관리자 권한 전환이 가능한 경우 |
| 조치 방법 | wheel 그룹 또는 sudoers 규칙을 통해 허용 사용자를 제한한다. |
| 조치 시 영향 | 일반적인 경우 영향 없음 |

## 점검 및 조치 사례

```bash
grep -E 'wheel|sudo' /etc/group /etc/sudoers
```

- 로그와 사용자 권한 상태를 함께 확인한다.
