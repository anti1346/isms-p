# U-10 동일한 UID 금지

| 구분 | 내용 |
| :--- | :--- |
| **개요** | |
| 점검 내용 | 시스템 내 중복 UID가 있는지 점검한다. |
| 점검 목적 | 권한 충돌을 방지하고 계정 식별을 일관되게 관리하기 위함 |
| 보안 위험 | 중복 UID는 권한 오인식과 의도하지 않은 접근 허용을 초래할 수 있다. |
| 참고 | ※ 해당 항목은 운영 환경 및 정책에 따라 세부 설정이 달라질 수 있다. |
| **점검 대상 및 판단 기준** | |
| 대상 | SOLARIS, LINUX, AIX, HP-UX 등 |
| 판단 기준 | **양호**: 모든 계정이 고유 UID를 가지는 경우<br>**취약**: 같은 UID를 가진 계정이 존재하는 경우 |
| 조치 방법 | 중복 UID를 가진 계정의 UID를 재지정하거나 계정을 정리한다. |
| 조치 시 영향 | 일반적인 경우 영향 없음 |

## 점검 및 조치 사례

```bash
awk -F: '{print $3}' /etc/passwd | sort | uniq -d
```

## AI 추천 점검 및 조치 방법

### 점검 포인트
- 해당 항목의 설정값이 실제 운영 환경에서 적용되는지 확인한다.
- 정책 기준과 현재 설정값을 비교한다.
- 로그와 사용자 권한 상태를 함께 확인한다.

### 권장 조치
