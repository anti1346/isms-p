# U-01 root 계정 원격 접속 제한

| 구분 | 내용 |
| :--- | :--- |
| **개요** | |
| 점검 내용 | 원격 관리 세션에서 root 직접 로그인 여부를 점검한다. |
| 점검 목적 | 관리자 권한이 원격에서 무분별하게 사용되지 않도록 차단하기 위함 |
| 보안 위험 | root 계정이 원격 접속에 허용되면 비인가자가 관리자 권한을 직접 획득할 수 있다. |
| 참고 | ※ 해당 항목은 운영 환경 및 정책에 따라 세부 설정이 달라질 수 있다. |
| **점검 대상 및 판단 기준** | |
| 대상 | SOLARIS, LINUX, AIX, HP-UX 등 |
| 판단 기준 | **양호**: 원격 접속 시 root 직접 로그인이 제한되고, 관리자 권한은 별도 관리 계정을 통해 수행되는 경우<br>**취약**: 원격 접속 시 root 직접 로그인이 허용되거나 관리자가 root로 직접 접속하는 경우 |
| 조치 방법 | SSH 설정에서 PermitRootLogin no를 적용하고 sudo 또는 별도 관리자 계정을 사용하도록 정책을 구성한다. |
| 조치 시 영향 | 일반적인 경우 영향 없음 |

## 점검 및 조치 사례

```bash
# SSH 설정 점검
grep -E 'PermitRootLogin|AllowUsers|DenyUsers' /etc/ssh/sshd_config

# root 직접 접속 제한 예시
PermitRootLogin no
```
