# U-02 비밀번호 관리정책 설정

| 구분 | 내용 |
| :--- | :--- |
| **개요** | |
| 점검 내용 | 비밀번호 정책 항목인 길이, 복잡도, 변경주기, 만료 주기 설정 여부를 점검한다. |
| 점검 목적 | 약한 비밀번호 사용을 차단하여 무차별 대입 공격을 방지하기 위함 |
| 보안 위험 | 짧거나 단순한 비밀번호는 빠르게 추측되어 계정 침해로 이어질 수 있다. |
| 참고 | ※ 해당 항목은 운영 환경 및 정책에 따라 세부 설정이 달라질 수 있다. |
| **점검 대상 및 판단 기준** | |
| 대상 | SOLARIS, LINUX, AIX, HP-UX 등 |
| 판단 기준 | **양호**: 비밀번호 최소 길이, 복잡도, 만료 기간 등이 정책에 따라 적절히 설정된 경우<br>**취약**: 비밀번호 정책이 미설정이거나 허용 범위가 과도하게 느슨한 경우 |
| 조치 방법 | /etc/login.defs 또는 시스템 정책 파일에서 비밀번호 최소 길이 및 변경 주기를 설정한다. |
| 조치 시 영향 | 일반적인 경우 영향 없음 |

## 점검 및 조치 사례

```bash
# 비밀번호 정책 점검
grep -E 'PASS_MAX_DAYS|PASS_MIN_DAYS|PASS_WARN_AGE|PASS_MIN_LEN' /etc/login.defs
```

## AI 추천 점검 및 조치 방법

### 점검 포인트
- 해당 항목의 설정값이 실제 운영 환경에서 적용되는지 확인한다.
- 정책 기준과 현재 설정값을 비교한다.
- 로그와 사용자 권한 상태를 함께 확인한다.

### 권장 조치
```bash
# 비밀번호 정책 점검
```

- 보안 정책을 반영해 설정을 조정한다.
- 불필요한 예외 설정을 제거한다.
- 변경 후 재점검을 수행한다.
